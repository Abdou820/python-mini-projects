# Python-Mini-Projects

A collection of small Python programs I built while learning the basics of programming.

These projects helped me practice logic, file handling, simple security concepts, and working with the terminal.

---

## What I Learned

While building these projects, I practiced:

- `if / elif / else` and `while` loops
- Working with lists and dictionaries
- Reading and writing files
- Handling basic errors (like dividing by zero or missing files)
- Using modules: `random`, `time`, `secrets`, `subprocess`
- Creating simple password tools and a basic encryption program
- Making programs that interact with the user in the terminal

---

## Projects

### Security Tools
- **Password Generator** – Creates strong random passwords using the `secrets` module
- **Password Strength Checker** – Checks how strong a password is and gives tips
- **Password Manager** – Saves website names, usernames, and passwords in a text file
- **Encryption Tool** – Encrypts and decrypts text using a Caesar cipher

### Other Tools
- **Calculator** – Simple calculator that can do multiple operations
- **Countdown Timer** – Counts down from the time you enter
- **To Do List** – Add, show, and delete tasks
- **WiFi Password Viewer** – Shows saved WiFi passwords on Windows
- **Number Guessing Game** – Guess the secret number
- **Learning Bot** – A small bot that can learn new answers from you and save them
